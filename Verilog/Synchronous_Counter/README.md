# 4-Bit Synchronous Counter using Verilog

## Overview
This project implements a 4-bit synchronous up-counter using Verilog HDL.

## Features
- Positive edge-triggered operation
- Active-high reset
- 4-bit up counter
- Simulated using ModelSim

## Files
- sync_counter.v
- tb_scount.v
- sync_counter_waveform.png

## Tools Used
- Verilog HDL
- ModelSim
